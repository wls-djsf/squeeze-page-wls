---

## 💻 Sobre o Projeto

Este projeto é uma **Squeeze Page pura** (página de captura de e-mails em tela única), construída para eliminar distrações e guiar o utilizador diretamente para a tomada de decisão (Call to Action). O layout foi desenhado em *Light Mode*, utilizando uma paleta de cores equilibrada, sombras suaves e proporções focadas na experiência do utilizador (UI/UX).

---

## 🛠️ Tecnologias e Conceitos Utilizados

* **HTML5 Semântico:** Estruturação correta das tags (`<main>`, `<div>`, `<form>`, `<input>`, `<button>`).
* **CSS3 Moderno:** 
  * **Flexbox:** Utilizado para centralização perfeita de elementos e alinhamento do formulário (input e botão lado a lado).
  * **Viewport Units (`vh` / `vw`):** Para fixar a estrutura na altura total da tela, garantindo que não haja barra de rolagem indesejada.
  * **Media Queries:** Responsividade adaptada para dispositivos móveis (smartphones), empilhando os elementos de forma fluida.
* **UI/UX Design:** Foco na lei da clareza visual, espaçamentos consistentes (`padding`/`margin`) e feedback de interação (`:hover` no botão de CTA).
* **Git & GitHub:** Versionamento de código e publicação web via GitHub Pages.
